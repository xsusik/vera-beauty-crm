# Vera Beauty Room — Studio Manager

Адаптивное CRM-PWA для beauty-студии в Польше. Интерфейс на польском языке. Проект можно разместить на Vercel как статический сайт.

## Быстрый запуск

PWA и Service Worker работают через HTTPS или локальный веб-сервер — открытие `index.html` двойным щелчком не включает установку и офлайн-режим.

- **Vercel:** загрузи проект целиком в GitHub и подключи репозиторий в Vercel. В `Settings → Build and Deployment → Root Directory` укажи папку, где рядом лежат `index.html` и `vercel.json`. Если они лежат в корне репозитория, оставь это поле пустым. `vercel.json` задаёт режим статического сайта без сборки. После изменения сделай новый деплой и открой ссылку `.vercel.app` из раздела `Deployments`. Из локальной папки можно запустить `npx vercel --prod`.
- **Локальный просмотр:** в папке проекта запусти `npx serve .` и открой адрес, показанный в терминале.
- **Установка:** открой сайт в Chrome или Edge и нажми «Zainstaluj» (если браузер предлагает установку). На iPhone/iPad в Safari нажми «Поделиться» → «На экран Домой».
- Для iPhone интерфейс учитывает безопасные зоны экрана и клавиатуру; системные шрифты помогают открываться без ожидания внешних загрузок.
- После первой загрузки приложение сможет открываться офлайн. Данные не очищаются при обновлении приложения.

## Что работает

- Plan dnia: визиты на сегодня и завтра, быстрый перенос и отмена, список напоминаний. Кнопка SMS открывает номер и готовый текст в «Сообщениях». Для польского девятизначного номера добавляется +48. Для другого государства указывай номер с кодом страны.
- Kalendarz: недельный и месячный календарь, добавление и редактирование визитов, поиск свободного времени по длительности услуги, рабочим часам и перерыву.
- Wizyty: статусы и оплата, SMS-шаблон, защита от пересечений. Удаление отдельного визита можно отменить кнопкой `Cofnij` в течение 20 секунд.
- Klientki: поиск, заметки, история и кнопка повторной записи. В `Lista oczekujących` можно добавить клиентку и подобрать её на освободившееся время.
- Usługi i cennik: редактирование услуг, цен, длительности.
- Finanse: оплаченная выручка, ожидаемые платежи, неоплаченные визиты, отчёт CSV.
- Ustawienia: название студии, телефон, адрес, Instagram, Facebook, часы работы.
- Копии данных: экспорт JSON на главном экране, дата последнего экспорта и напоминание через семь дней. Импорт JSON в настройках. CSV для визитов, клиентов и финансов.
- Установка на главный экран, собственные иконки и офлайн-запуск.
- Адаптивный интерфейс для смартфонов и компьютеров.

## Уведомления маме при закрытой CRM

Код Web Push подготовлен для Vercel Functions и Upstash Redis. Активация требует подключения внешних сервисов и проверки на настоящем iPhone.

1. Подключи Upstash Redis к проекту Vercel. В Production Environment Variables добавь `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
2. В папке проекта выполни `npm ci`, затем `npx web-push generate-vapid-keys --json`. Сохрани выданные ключи в переменных Vercel `VAPID_PUBLIC_KEY` и `VAPID_PRIVATE_KEY`. Для `VAPID_SUBJECT` укажи свой контакт в формате `mailto:адрес-почты`.
3. Сгенерируй два независимых случайных секрета командой `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Один сохрани как `PUSH_ACCESS_KEY`, второй как `CRON_SECRET`. Значения задаются в настройках Vercel. Секреты должны храниться вне GitHub.
4. Загрузи изменения, включая `package.json`, `package-lock.json`, `api/`, `push.js`, `sw.js` и `vercel.json`, и выполни Production Deploy. Исключи из загрузки `node_modules/`, `.vercel/` и файлы с секретами `.env`. Root Directory должна указывать на папку с `index.html`. Деплой устанавливает серверную зависимость через `npm ci`.
5. На iPhone открой окончательный адрес CRM в Safari и добавь на экран «Домой». Открой приложение с иконки. В `Ustawienia → Ustaw powiadomienia` введи `PUSH_ACCESS_KEY`, нажми `Włącz powiadomienia` и разреши уведомления.
6. Нажми `Wyślij powiadomienie testowe`, заблокируй телефон и проверь получение и открытие списка SMS. Затем создай тестовый визит на завтра и проверь запуск задания в Vercel Cron Jobs.

Задание запускается ежедневно в 08:00 UTC — 09:00 зимой и 10:00 летом в Польше. Фактическая точность запуска зависит от тарифа Vercel. Напоминание приходит, если на завтра есть визиты без отметки отправленного SMS. Время выбрано по умолчанию. Для проверки вручную можно запустить Cron Job в панели Vercel. После сетевой ошибки повторный запуск безопасен для уже обработанных устройств. При неопределённом результате доставки возможен повтор с тем же notification tag.

На сервер передаются push-подписка устройства и список дат с неотправленными напоминаниями. Имена, телефоны, заметки и текст SMS хранятся в браузере. После изменения визитов телефон должен подключиться к интернету для обновления расписания. Интерфейс показывает ошибку синхронизации. При отсутствии связи сервер использует последнее полученное расписание.

Открытие SMS само по себе не отмечает его отправленным. Мама отправляет сообщение в «Сообщениях», возвращается в CRM и нажимает `Oznacz jako wysłany`. Уведомление открывает актуальный список. На iPhone требуется проверка передачи готового текста в системное приложение, браузерная эмуляция этого не проверяет.

Подключение поддерживает до пяти устройств. Их CRM-базы независимы. Подписка удаляется после 90 дней без открытия и синхронизации приложения или при ответе push-сервиса об истечении подписки. После этого уведомления нужно включить повторно.

## Первая настройка

1. При первом открытии база пустая — добавь свои услуги в `Usługi i cennik` и настрой контакты студии в `Ustawienia`.
2. Добавляй клиенток и визиты. Изменения автоматически сохраняются в браузере.
3. Регулярно скачивай JSON-копию кнопкой `Pobierz kopię` на экране `Plan dnia` и сохраняй её за пределами устройства. Для восстановления открой `Ustawienia → Wczytaj JSON`. Импорт заменяет текущую базу.
4. Отдельные записи можно удалить в соответствующих разделах. Для полного удаления используй действие очистки данных в `Ustawienia`.

## Важно о безопасности

Данные CRM сохраняются в `localStorage` этого браузера на этом устройстве, а не в Vercel. Они не синхронизируются между устройствами/браузерами и могут быть доступны другим людям с доступом к этому профилю браузера. Очистка данных браузера может удалить записи — регулярно сохраняй JSON-копию. PWA и офлайн-режим не являются резервной копией.

В этой версии нет учётных записей, общей облачной базы или серверного шифрования. Не используй её для хранения чувствительных данных реальных клиенток в публичной среде без backend, авторизации, разграничения доступа, безопасных резервных копий и соблюдения RODO/GDPR. Для работы на нескольких устройствах нужен отдельный защищённый backend. SMS формируется вручную, без автоматической отправки. Instagram/Facebook служат ссылками; интеграции с их сообщениями нет.

Финансовые отчёты — управленческие, не бухгалтерские.
